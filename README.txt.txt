RADIO ZIKI — Privatni projekat autora

Ova web stranica je javno dostupna samo za prikaz i korištenje,
ali sav kod i funkcionalnosti su zaštićeni i pripadaju autoru.

Nije dozvoljeno kopiranje, mijenjanje, dijeljenje ili korištenje ovog koda
bez izričite dozvole autora.

Stranica sadrži:
- HTML (index.html)
- Ugrađeni CSS i JavaScript
- PWA ikone i funkcije
- Firebase i CDN resurse
